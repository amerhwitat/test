NETWORK ROUTING

Proxy, firewall & VPN

Browser WebRTC media uses ICE, STUN and TURN. HTTP/SOCKS proxy settings generally affect signaling or app traffic, not arbitrary WebRTC UDP media. For restrictive networks, configure a TURN server reachable over TLS/TCP port 443. For a full VPN tunnel, use an OS VPN (for example WireGuard/OpenVPN) or a managed native VPN adapter; a web page cannot safely install or embed privileged VPN drivers.

Use short-lived TURN credentials from a trusted backend in production; do not store permanent TURN secrets in browser local storage.

Privacy & network note

Only peers sharing a room are discovered. The signaling server necessarily sees the connecting IP; host-side persistence and sharing that address with room peers require separate explicit consent. WebRTC media is encrypted in transit. TURN relays media when direct paths fail; it does not decrypt and mix streams. Deploy with HTTPS/WSS, authentication, room secrets, rate limits and an authenticated TURN credential service.
